¿Qué es un caso de pruebas?

Concepto General

Un Caso de Prueba (Test Case) es un documento o conjunto de condiciones estructuradas con las cuales un evaluador o tester determina si un sistema, software o funcionalidad cumple con los requisitos especificados y funciona correctamente.

Su objetivo fundamental es validar que una entrada dada (input) produzca el resultado esperado (output) de forma repetible y controlada.

Estructura Básica de un Caso de Prueba

1. ID del Caso

Identificador único dentro del proyecto (Ejemplo: CP-001).

2. Nombre / Título

Descripción clara y objetiva de la funcionalidad que se va a probar.

3. Precondiciones

Requisitos previos necesarios para ejecutar la prueba (Ej: Tener sesión iniciada).

4. Pasos a Ejecutar

Secuencia numérica y ordenada de acciones que realiza el usuario.

5. Datos de Entrada

Valores exactos utilizados durante la prueba (usuarios, claves, textos).

6. Resultado Esperado

La respuesta correcta que la aplicación debe ofrecer si la prueba es exitosa.

Ejemplo Práctico

Campo Detalle
ID del Caso: CP-LOGIN-001
Nombre: Iniciar sesión con credenciales válidas
Precondiciones: El usuario debe estar registrado activamente en la plataforma.
Pasos: 1. Navegar a /login.
2. Ingresar correo registrado.
3. Ingresar contraseña correcta.
4. Clic en 'Ingresar'.
Resultado Esperado: El sistema redirige al tablero principal y muestra el mensaje de bienvenida.
